# ÉCLAT — Luxury Concept Store

Responsive, animated single-page luxury concept-store website.

## Publish with GitHub Pages
1. Upload `index.html` to the root of the `main` branch.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then save.
5. After deployment, the public website will be available at https://pujabhemani07.github.io/eclat-luxury-store/.

## Demo limitations
Sample product details and imagery are placeholders. The shopping bag is front-end only; payment, inventory, shipping, customer accounts and order processing are not connected. Replace all demo content before using this as a live store.
